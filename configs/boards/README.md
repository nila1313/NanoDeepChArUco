# Board definitions

| File | Geometry | Dictionary | ChArUco corners |
|---|---|---|---:|
| `large_7x7_dict4x4_50.npy` | 7 x 7 squares | DICT_4X4_50 | 36 |
| `small_5x6_dict6x6_250_meters.npy` | 5 x 6 squares | DICT_6X6_250 | 20 |

Do not substitute one board for the other. Physical dimensions are stored in
each NumPy dictionary and are passed unchanged to CalibCam.
